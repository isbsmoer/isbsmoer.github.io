# 着せ替えWebアプリ一括生成指示書 (GitHub Copilot用・配色全変数化完全版)

GitHub Copilot へのプロンプトとしてそのままコピー＆ペーストして使用してください。以下の指示に従って `index.html`、`css/style.css`、`js/script.js` を生成してください。

---

## 1. テーマ・デザインイメージ・レイアウト指定
- 【選択テーマ】: [ オリジナルイラストで楽しむ着せ替えコーディネートWebアプリ ]
- 【参考イメージ (雰囲気)】: [ 手描きイラストの魅力が引き立つ、温かみがあり明るく親しみやすいアトリエ風デザイン ]
- 【レイアウト指定】: [ 3カラム構成：左側に固定サイドバー（ヘッダー・ロゴ・説明・リセット/保存アクション）、中央にリアルタイム着せ替えプレビュー画面、右側にカテゴリタブ＆コーディネートパーツ選択グリッド（スマホ時は縦積みレスポンシブ） ]

## 2. フォルダ構成・ファイル仕様
- 以下のファイル・フォルダ構造で作成し、外部CSSライブラリ（BootstrapやTailwind等）は使用しないこと
  - `index.html` (プロジェクト直下)
  - `css/style.css`
  - `js/script.js`
- `index.html` 内で `css/style.css` と `js/script.js` を読み込むこと

## 3. セクション・機能構成・データ構造指定
1. 左側固定ヘッダー・サイドバーエリア
   - アプリタイトル・ロゴ、簡単な説明文
   - 全パーツリセットボタン、現在のコーディネートをPNG画像としてダウンロードするボタン
2. 中央プレビューエリア
   - 選択された各パーツの透過PNGイラストを正しい重ね順（レイヤー構造）でリアルタイム表示するプレビュー枠
   - ベースとなるボディ（素体）レイヤーと、選択中のコーディネート一覧・解除操作を表示
3. 右側コーディネート選択エリア
   - カテゴリタブ（以下の順番で配置すること：トップス、アウター、インナー、パンツ、スカート、ワンピース、靴下、靴、アクセサリー の合計9カテゴリ）
   - 選択中のカテゴリに応じたパーツ一覧グリッドの動的描画（「なし／外す」を選べるカテゴリには「なし」ボタンを自動配置すること。例：アウター、パンツ、スカート、ワンピース、靴下、靴、アクセサリー等）
   - パーツクリック時に中央プレビューへ即座に反映し、選択中アイテムをハイライト表示
※パーツの定義や画像ファイルパスは、後から自作イラストの透過PNGパス（例: `images/tops/tops_01.png`）をそのまま追記・差し替えできるよう、`js/script.js` の冒頭に独立した構造化データ（`const WARDROBE_DATA = {...}`）として定義し、DOM操作で動的に描画すること。ダミー画像やプレースホルダー画像は一切挿入しないこと。

## 4. デザイン・CSS仕様
- Google Fonts から以下の2種類のフォントを `index.html` の `<head>` 内で読み込み適用すること
  - 欧文フォント: `Fredoka`
  - 和文フォント: `Zen Maru Gothic`
- `css/style.css` 冒頭の `:root` に以下の基本変数を定義し、説明コメントを付与すること
  - `--font_en`: 'Fredoka', sans-serif
  - `--font_ja`: 'Zen Maru Gothic', sans-serif
  - `--font-family`: `var(--font_en), var(--font_ja)`
  - `--primary-color`（例: `#E07A5F`）
  - `--secondary-color`（例: `#81B29A`）
  - `--bg-color`（例: `#FFF9F2`）
  - `--text-color`（例: `#3A322D`）
- 【配色完全変数化ルール】
  - `css/style.css` 内のすべての配色指定（背景色・文字色・ボタン・ホバー時・枠線・影等）に直接のカラーコード（`#xxxxxx` や `rgb(...)`）を記述することは一切厳禁とする。
  - 追加で使用する色（表面色、枠線、ホバー色、アクセント、影など）はすべて `:root` にCSS変数として定義し、必ず `var(...)` で参照すること。
- スマホ表示対応（`@media max-width: 768px`）のレスポンシブCSSを実装し、デスクトップでは左固定サイドバー＋中央プレビュー＋右パーツ選択の3カラム、スマホでは縦並びの使いやすいレイアウトにすること
- ボタンのホバー、パーツカードの選択状態（`active`）とホバー時の浮き上がり（`transform`）、切り替えアニメーションを実装すること

## 5. 画像・Canvas合成仕様
- 自作イラストの透過PNGを重ね合わせることを前提とし、自然な着せ替えの重なり順（例：ベース素体 ＞ 靴下 ＞ 靴 ＞ パンツ・スカート・ワンピース ＞ インナー ＞ トップス ＞ アウター ＞ アクセサリー）でHTMLレイヤー重ね順およびHTML5 `<canvas>` による画像書き出し処理（`canvas.toDataURL('image/png')`）を実装すること
- 画像パス（`src` / `image` フィールド）は空文字 `""` または未設定でもエラーにならないよう安全にハンドリングし、自作の透過PNGパスを入力した瞬間にプレビューとPNG書き出しの両方に反映される構造にすること

## 6. 出力ルール
- 前置き・解説文・まとめの文章は一切出力せず、`index.html`、`css/style.css`、`js/script.js` の完全なコードブロックのみを出力すること。
