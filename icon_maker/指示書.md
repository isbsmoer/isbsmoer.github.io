# 汎用Webアプリ一括生成指示書 (配色全変数化・完全決定版)

## 1. テーマ・デザインイメージ・レイアウト指定
- 【選択テーマ】: [男女両対応のオープンピープル風カスタムアイコン作成メーカー]
- 【参考サイト (URL)】: [ https://www.openpeeps.com/ ]
- 【参考イメージ (雰囲気)】: [ 自由でポップ、温かみのある手描きイラスト風のカジュアルで楽しい雰囲気 ]
- 【レイアウト指定】: [ 左側にプレビュー＆操作パネル、右側にタブ切り替え＆パーツ選択グリッド（スマホでは上部プレビュー・下部操作パネルのレスポンシブ構成） ]

## 2. フォルダ構成・ファイル仕様
- 以下のファイル・フォルダ構造で作成し、外部CSSライブラリは使用しないこと
  - `index.html` (プロジェクト直下)
  - `css/style.css`
  - `js/script.js`
- `index.html` 内で `css/style.css` と `js/script.js` を読み込むこと

## 3. セクション構成・データ構造指定
1. ヘッダー / タイトルエリア (アプリ名、簡単な説明文)
2. プレビューエリア (選択された各パーツをレイヤー構造で重ねてリアルタイム表示する正方形のプレビューボックス、および背景色プレビュー)
3. コントロール・カテゴリタブエリア (以下の順番でタブを配置すること：体、前髪、後ろ髪、鼻、口、眉毛、目、チーク、輪郭、背景色の合計10カテゴリ)
4. パーツ選択グリッドエリア (選択中のカテゴリに応じたパーツ一覧の動的描画。「なし」を選べるパーツには「なし」ボタンを自動で用意すること)
5. オプション・アクションエリア (背景色パレット＆自由選択カラーピッカー、ランダム自動生成ボタン、必須パーツ未選択時のモーダル警告付きPNG保存ボタン)
※パーツの画像ファイルパスやカテゴリ定義は、ユーザーが後から自身のProcreate等で作成した透過PNG画像をそのままはめ込めるよう、`js/script.js` の冒頭に「独立した構造化データ（const PARTS_DATA = {...} ※items内は空配列またはパス記述用の枠組み）」として定義し、DOM操作で動的に描画すること。ダミー画像やプレースホルダー画像は一切挿入しないこと。

## 4. Design & CSS Specifications 
- Google Fonts から以下のフォントを index.html の <head> 内で読み込み適用すること
  - 欧文フォント: [ Fredoka ]
  - 和文フォント: [ Zen Maru Gothic ]
- css/style.css 冒頭の `:root` に以下の基本変数を定義し、説明コメントを付与すること
  - `--font_en`: 欧文フォント指定
  - `--font_ja`: 和文フォント指定
  - `--font-family`: `var(--font_en), var(--font_ja)`
  - `--primary-color`, `--secondary-color`, `--bg-color`, `--text-color`
- 【配色完全変数化ルール】
  - css/style.css 内のすべての配色指定（背景色・文字色・ボタン・ホバー時・枠線・影等）に直接のカラーコード（#xxxxxx）を記述することは一切厳禁とする。
  - AIが追加で差し色や装飾用カラーを使用したい場合は、必ず `:root` 内に新しいCSS変数（例: `--accent-color`, `--border-color`, `--hover-color`, `--surface-color` 等）を追加定義し、常に `var(...)` 経由で適用すること。
- スマホ表示対応（@media max-width: 768px）のレスポンシブCSSも併せて出力すること
- ボタンのホバー、カードの選択状態(`active`)、おしゃれな警告モーダルのふんわり出現アニメーションはAI側で自動実装すること

## 5. 画像・canvas仕様
- パーツ画像は透過PNGを想定し、レイヤーが自然に重なる順序（例：体 ＞ 後ろ髪 ＞ 輪郭 ＞ 口 ＞ 鼻 ＞ 目 ＞ 眉毛 ＞ チーク ＞ 前髪、等）にHTMLの重ね順およびJSのCanvas合成処理（`canvas.toDataURL`）を実装すること
- 画像パスはすべて空の状態にし、自身で描いた透過PNGファイル（例: `images/face/face_01.png` 等）のパスを後からはめ込むだけで即座に動く状態にしておくこと

## 6. Output Rules
- 前置き・解説文・まとめの文章は一切出力禁止
- index.html, css/style.css, js/script.js の完全なコードブロックのみを出力すること
