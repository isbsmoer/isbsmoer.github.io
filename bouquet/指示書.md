# 汎用Webアプリ一括生成指示書 (配色全変数化・完全決定版)

## 1. テーマ・デザインイメージ・レイアウト指定
- 【選択テーマ】: [ 贈る相手やシーンに合わせて花言葉から最適な花束を提案してくれるフラワーギフト＆花言葉図鑑Webアプリ ]
- 【参考サイト (URL)】: [ なし（直感的な花束診断パネルと色別・花言葉別の花材図鑑を連動させたモダンUI） ]
- 【参考イメージ (雰囲気)】: [ 生花店のアトリエのような洗練された温かみと透明感、花の色や花言葉が美しく引き立つ上品で親しみやすい雰囲気 ]
- 【レイアウト指定】: [ 画面上部で花束を診断し、下部は「花束の提案結果エリア（左）」と「花の種類・色・花言葉一覧エリア（右）」を並べた2カラム・アトリエボードレイアウト（スマホ時は縦積み） : 診断と図鑑を同時に見比べやすい視認性の高いスタイル ]

## 2. フォルダ構成・ファイル仕様
- 以下のファイル・フォルダ構造で作成し、外部CSSライブラリは使用しないこと
  - `index.html` (プロジェクト直下)
  - `css/style.css`
  - `js/script.js`
- `index.html` 内で `css/style.css` と `js/script.js` を読み込むこと

## 3. セクション・機能構成・データ構造指定
1. ヘッダー (アプリロゴ、サブタイトル、ナビゲーションリンク：「花束を診断する」「提案と花言葉一覧」)
2. ヒーロー＆花束診断バー (キャッチコピー: [ 想いを花言葉に託して、世界にひとつの花束を。 ]、サブコピー、メインビジュアル、および以下の選択項目を備えた診断フォーム)
   - ① 贈る相手（恋人・パートナー / 友人・同僚 / 家族・両親 / お世話になった目上の方 / 自分へのご褒美）
   - ② 贈るタイミング・シーン（誕生日 / 感謝・お礼 / お祝い・門出 / 励まし・応援 / 記念日・特別な日）
   - ③ 希望のメインカラー（おまかせ / ピンク系 / レッド系 / イエロー・オレンジ系 / ホワイト・グリーン系 / ブルー・パープル系）
   - 「花束のアイデアを見る」ボタン
3. メイン2カラムボードエリア (`js/script.js` 内の配列データおよび `localStorage` から動的描画)
   - **左カラム：花束の提案結果＆お気に入りエリア**
     - 診断条件にマッチしたおすすめ花束のテーマタイトル＆コンセプト説明
     - 組み合わせる花材リスト（3〜4種類：花名・色・花言葉・役割［メイン／サブ／グリーン］）
     - ラッピングやメッセージカードに添える一言アドバイス
     - 「別の組み合わせを再提案する」ボタン＆お気に入り保存ボタン（`localStorage` に保存・一覧表示・削除可能）
   - **右カラム：花の種類・色・花言葉一覧（花言葉図鑑）エリア**
     - 色別フィルタータブ（すべて / ピンク / レッド / イエロー・オレンジ / ホワイト / ブルー・パープル / グリーン）およびキーワード検索（花名・花言葉で検索）
     - 各花カードの表示内容：花のイメージ画像、花名（和名・英名）、カラータグ、代表的な花言葉、おすすめの贈るシーン
4. フッター
※未記入の項目はテーマおよび参考イメージに合わせた最適な内容をAIが自動補完すること。
※花材データベース（花名・色・花言葉・対応シーン・解説など）のデータは、後から編集・追加しやすいよう `js/script.js` の冒頭に「独立した配列データ（const ... = [...]）」として定義し、DOM操作で描画すること。

## 4. デザイン・CSS仕様 (カスタマイズ前提)
- Google Fonts から以下の2種類のフォントを `index.html` の `<head>` 内で読み込み適用すること
  - 欧文フォント: [ Cormorant Garamond ]
  - 和文フォント: [ Zen Maru Gothic ]
  ※未指定・空欄の場合はテーマに最適な組み合わせをAIが自動選定すること。
- `css/style.css` 冒頭の `:root` に以下の基本変数を定義し、説明コメントを付与すること
  - `--font_en`: 'Cormorant Garamond', serif
  - `--font_ja`: 'Zen Maru Gothic', sans-serif
  - `--font-family`: `var(--font_en), var(--font_ja)`
  - `--primary-color`, `--secondary-color`, `--bg-color`, `--text-color`
- 【配色完全変数化ルール】
  - `css/style.css` 内のすべての配色指定（背景色・文字色・ボタン・ホバー時・枠線・影・花の色バッジ等）に直接のカラーコード（`#xxxxxx` や `rgb(...)`）を記述することは一切厳禁とする。
  - AIが追加で差し色や装飾用カラー（例: `--accent-color`, `--card-bg-color`, `--border-color`, `--hover-color`, `--tag-pink`, `--tag-red`, `--tag-yellow`, `--tag-white`, `--tag-blue`, `--tag-green` 等）を使用したい場合は、必ず `:root` 内に新しいCSS変数を追加定義し、常に `var(...)` 経由で適用すること。
- スマホ表示対応（`@media max-width: 768px`）のレスポンシブCSSも併せて出力すること
- ボタンのホバー、カードの浮き上がり(`transform`)、提案結果のフェードインアニメーションはAI側で自動実装すること
