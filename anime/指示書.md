# ワークシートの作成（アニメのセリフクイズ ウェブアプリ仕様書）

## 1. 企画・コンセプト・デザイン指定
【選択テーマ】
『SLAM DUNK（スラムダンク）』をはじめとする人気アニメの名言・セリフを当てて遊ぶ、スマホ（SP）特化型の「アニメのセリフクイズ」ウェブアプリ

【参考にするイメージ】
熱い名シーンのワクワク感と、ポップで遊びやすいミニゲームUIの両立。プレイヤー自身がフォント・背景色・フレーム装飾をリアルタイムで着せ替えでき、スマホでサクサク遊んだり、結果や問題集をPDFとして印刷・保存したりできる体験。

【レイアウト・画面構成指定】
・SP（スマートフォン）特化レイアウト：PC閲覧時も中央にスマホ画面サイズ（max-width: 430px前後）で固定表示し、背景を落ち着いたトーンにする。
・両端固定・中央スクロール構造：画面上部（ヘッダー：タイトル・スコア／モード切替・印刷ボタン等）と下部（フッター：デザインカスタム操作パネル・ナビゲーション）を固定し、中央のクイズ出題＆回答エリアのみが縦スクロールできるアプリライクなUI。

【Google Fonts名（アプリUIおよび着せ替え選択肢）】
・ベースUI・デフォルトフォント：Zen Maru Gothic（丸みがあり親しみやすいゴシック体）
・ユーザー選択用フォント（問題文・選択肢・タイトル用）：
  - Mochiy Pop One（元気でインパクトのあるポップ体・熱血シーン向け）
  - Kiwi Maru（少しクセがあって絵本のような愛らしさのあるフォント）
  - Shippori Mincho（重厚感やドラマチックな名言に合う明朝体）
  - Cormorant Garamond（クールな決めゼリフや海外風演出に合う欧文セリフ体）

【色の指定（デフォルトカラー＆着せ替えパレット）】
・ベース背景色（デフォルト）：#FFF8E9（温かみのあるクリーム色） / #FFFCF7（オフホワイト）
・アクセント・テーマカラー候補：
  - #FF7A9E（コーラルピンク：ポップ・青春演出向け）
  - #2A75E6（スカイブルー：クール・冷静なキャラクター向け）
  - #FFC72C（マスタードイエロー：コートや照明のような明るいアクセント向け）
  - #6BCB77（ミントグリーン：フレッシュ・応援演出向け）


## 2. コンテンツ・文章・機能指定
【アプリタイトル・キャッチコピー】
あの名シーンの言葉を思い出せ！「アニメのセリフクイズ」

【実装するコア機能（3つ）】
① セリフクイズ出題・回答・判定機能
・クイズ出題：名言・セリフを表示し、「誰のセリフか」「どの場面・作品のセリフか」を4択や入力形式で回答できる。
・即座のフィードバック＆スコア管理：正解・不正解の演出、コンボやスコアの集計、解説・シーンメモの表示を行う。
・問題追加・カスタム出題（任意）：自分でオリジナル問題を追加したり、出題カテゴリ（スラムダンク／キャラクター別／名シーン別など）を切り替えたりできる。

② リアルタイム・デザインカスタマイズ機能（下部パネル操作）
・フォント変更：クイズ画面全体のフォントをワンタップで切り替え。
・背景色・テーマカラー変更：プリセットのカラーパレットやカラーピッカーで背景色・ボタン・見出し色を変更。
・フレーム・装飾の切り替え：「シンプル枠」「ドット・破線」「ポラロイド風」「マスキングテープ風」「切符（チケット）風」など、クイズカードや画面全体の枠線装飾を切り替えられる。

③ プレイ／閲覧モード ＆ PDF印刷出力機能
・モード切替：クイズに挑戦する「プレイモード」と、全問題・解説・スコア結果を一覧で見返せる「一覧／閲覧モード」を切り替えられる（localStorage へのスコア・設定自動保存対応）。
・PDF・印刷最適化（@media print）：固定ヘッダー・フッターや操作ボタンを印刷時に自動で非表示にし、問題集や結果シートだけを綺麗なレイアウトでPDF保存・印刷ができる。

【初期サンプルデータ（起動時に表示されるダミーデータ）】

① 基本情報・クイズ状態データ（quizState）
・タイトル：SLAM DUNK 名セリフクイズ
・サブタイトル／説明：湘北高校バスケ部を中心に、心に残る名言・決めゼリフに挑戦！
・現在のスコア／問題番号：0 / 第1問
・カバー／演出画像：デフォルトのサンプル画像（差し替え可能）

② クイズ問題一覧データ（quizList 配列で動的カード描画）
・問題1：「あきらめたらそこで試合終了ですよ。」 / 選択肢：安西先生・桜木花道・流川楓・赤木剛憲 / 正解：安西先生 / 解説：陵南戦後半、三井寿にかけた伝説の言葉。
・問題2：「左手はそえるだけ…」 / 選択肢：宮城リョータ・桜木花道・三井寿・木暮公延 / 正解：桜木花道 / 解説：ジャンプシュートのフォームを教わった際の合言葉。
・問題3：「バスケが…したいです…」 / 選択肢：三井寿・水戸洋平・仙道彰・魚住純 / 正解：三井寿 / 解説：体育館での乱闘後、安西先生の前で本音を吐露した名シーン。

③ デザイン設定データ（designTheme）
・fontFamily：'Mochiy Pop One'
・bgColor：'#FFF8E9'
・accentColor：'#FF7A9E'
・frameStyle：'ticket'（切符風 / ステッチ風 / ポラロイド風 / シンプル枠 から選択）


## 4. 実装・ファイル構成ルール
・HTML / CSS / JavaScript は役割ごとに別ファイル（index.html / style.css / script.js）へ分離して出力すること。
・CSSの :root にテーマカラーやフォント用のカスタム変数（--bg-color, --accent-color, --main-font 等）を定義し、JavaScriptからのデザイン変更はCSS変数の書き換えでリアルタイムに反映させること。
