  - `js/script.js`

## 3. セクション・機能構成・データ構造指定
1. ヘッダー (アプリロゴ、キャッチコピー、新規お店登録モーダルを開くボタン)
2. 検索・絞り込みコントロールバー
   - 地域（エリア）別フィルター（例：すべて、東京、北海道、大阪、福岡 など登録データから動的生成または選択）
   - ステータス切り替えタブ（「すべて」「行ってみたい（Wishlist）」「行った！（Visited）」）
   - 現在地周辺のお店を探すボタン（ブラウザの位置情報取得 API を使用し、地図を現在地へ移動）
3. インタラクティブ地図エリア (Leaflet.js + OpenStreetMap を使用)
   - 登録された飲食店のピン表示（「行ってみたい」と「行った！」でピンの色やアイコンを区別）
   - 地図上の任意の場所をクリックすると緯度・経度を取得し、そのまま新規登録フォームへ反映できる機能
   - ピンクリック時に店名・エリア・ステータス・サムネイルをポップアップ表示
4. 飲食店一覧・記録カードエリア (`js/script.js` 内の配列データおよび `localStorage` から動的描画)
   - 各カードの表示内容：お店の写真（未登録時はダミー画像）、店名、地域（エリア）、ジャンル、ステータスバッジ（行ってみたい／行った！）、メモ・感想コメント、地図で場所を見るボタン、編集・削除ボタン
   - 「行った！」へのステータス切り替えボタン（クリックで即座に訪問済みへ変更・再編集可能）
5. 新規登録・編集モーダル（またはアコーディオンフォーム）
   - 入力項目：店名、地域（エリア）、ジャンル、緯度・経度（地図クリックまたは住所/スポット選択で自動入力）、ステータス（行ってみたい / 行った！）、写真アップロード（`<input type="file" accept="image/*">` で FileReader によりプレビュー＆保存）、コメント・感想入力欄
6. よくある質問 / 使い方ガイド FAQ (`js/script.js` で質問クリック時にアコーディオンが開閉する動作)
7. フッター
※未記入の項目はテーマおよび参考イメージに合わせた最適な内容をAIが自動補完すること。
※初期サンプルデータ・FAQのデータは、後から編集しやすいよう `js/script.js` の冒頭に「独立した配列データ（const ... = [...]）」として定義し、初回起動時に `localStorage` へ保存してDOM操作で描画すること。

## 4. デザイン・CSS仕様 (カスタマイズ前提)
- Google Fonts から以下の2種類のフォントを `index.html` の `<head>` 内で読み込み適用すること
  - 欧文フォント: [ Fredoka ]
  - 和文フォント: [ Zen Maru Gothic ]
  ※未指定・空欄の場合はテーマに最適な組み合わせをAIが自動選定すること。
- `css/style.css` 冒頭の `:root` に以下の基本変数を定義し、説明コメントを付与すること
  - `--font_en`: 'Fredoka', sans-serif
  - `--font_ja`: 'Zen Maru Gothic', sans-serif
  - `--font-family`: `var(--font_en), var(--font_ja)`
  - `--primary-color`, `--secondary-color`, `--bg-color`, `--text-color`
- 【配色完全変数化ルール】
  - `css/style.css` 内のすべての配色指定（背景色・文字色・ボタン・ホバー時・枠線・影等）に直接のカラーコード（`#xxxxxx` や `rgb(...)`）を記述することは一切厳禁とする。
  - AIが追加で差し色や装飾用カラーを使用したい場合は、必ず `:root` 内に新しいCSS変数（例: `--accent-color`, `--visited-color`, `--wishlist-color`, `--border-color`, `--card-bg-color`, `--shadow-color` 等）を追加定義し、常に `var(...)` 経由で適用すること。
- スマホ表示対応（`@media max-width: 768px`）のレスポンシブCSSも併せて出力すること
- ボタンのホバー、カードの浮き上がり(`transform`)、モーダル表示アニメーション、FAQアコーディオンアニメーションはAI側で自動実装すること

## 5. 画像指定
- 初期サンプルデータおよび画像未設定時のフォールバック用として `placehold.jp` のダミー画像URLを使用すること
  - 飲食店サンプル画像: `https://placehold.jp/600x400.png?text=Gourmet+Photo`
  - ユーザー／アイコン画像: `https://placehold.jp/150x150.png?text=Shop`
- ユーザーがフォームから選択したローカル画像は `FileReader` (Base64形式) を用いてブラウザ上でプレビュー表示および `localStorage` に保存・描画できるようにすること
