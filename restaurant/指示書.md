# プロジェクト概要: 昔ながらの洋食レストラン Webサイト制作

## 1. プロジェクトの目的と成果地点（CV）
- 目的: レトロで暖かみのある店舗の魅力を伝え、サイト内予約フォームからの予約獲得につなげる。
- メインCV: 予約フォームからの送信完了、および電話発信リンクのタップ

## 2. ターゲットユーザー
- ランチ: ママ友グループ（子連れ歓迎、ゆったり過ごせる空間）
- ディナー: ファミリー層（子供向けメニュー、家族で楽しめるアットホーム感）

## 3. デザイン・世界観
- トーン＆マナー: レトロ・レトロモダン・暖かみ・クラシック
- カラーパレット:
  - メインカラー: ブラウン / レンガ色（暖かみ・伝統感）
  - サブカラー: クリーム / 生成り色（やわらかさ・安心感）
  - アクセントカラー: マスタードイエローまたは深みのある赤（予約ボタン・注目要素）
- フォントイメージ: 親しみやすく温もりを感じるフォント設定

## 4. サイト構成（シングルページ LP構成）
1. **ヘッダー**: ロゴ、ナビゲーション、固定「Web予約」ボタン
2. **ヒーローセクション**: キャッチコピー + メインビジュアル + CVボタン
3. **コンセプト / こだわり**: 昔ながらの味・お子様連れ歓迎の安心感
4. **おすすめメニュー**: ランチ・ディナー・キッズプレート・デザート（タブ切り替えまたはカード配置）
5. **店内・空間紹介**: テーブル席、ベビーカー対応、個室/ボックス席
6. **予約フォーム（モーダルまたはセクション表示）**: 
   - お名前、電話番号、メールアドレス、ご来店日時、人数（大人・子供）、ご要望（ベビーカー設置等）
7. **店舗情報・アクセス**: 営業時間、住所、アクセス方法、Google Map埋め込み枠
8. **フッター**: コピーライト、スマホ固定表示の予約/電話ボタン（画面下部追従）

## 5. 技術スタック・実装ルール
- **技術**: HTML5, CSS3, JavaScript (Vanilla JS / 外部ライブラリ非依存)
- **レスポンシブデザイン**: モバイルファースト設計（スマホ・タブレット・PC対応）
- **CSS設計**: セマンティックな記述、変数（CSS Custom Properties）を活用したカラー・フォントの一括管理
- **JavaScript実装範囲**:
  - モバイル用ハンバーガーメニューの開閉
  - 予約フォームのバリデーション（必須項目チェック・日時選択）
  - 送信完了時のモーダル/メッセージ表示
  - スムーススクロール実装
